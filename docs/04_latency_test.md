# 03 - Cloud Migration Advisor

## Objetivo

Cargar el reporte JSON generado por CPAT en Cloud Migration Advisor para obtener recomendacion del metodo de migracion.

## Flujo

1. Abrir Cloud Migration Advisor desde el ambiente del laboratorio.
2. Seleccionar Guided Mode.
3. Elegir que el destino ya esta definido.
4. Seleccionar Autonomous Database Serverless.
5. Cargar el reporte JSON de CPAT.
6. Revisar la solucion recomendada.

## Evidencia esperada

- Captura de carga del JSON CPAT.
- Captura del Solution Report.
- Recomendacion de Data Pump Conventional Export/Import para los flujos del laboratorio.
