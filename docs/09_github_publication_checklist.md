# 08 - Database Actions

## Objetivo

Validar tareas administrativas y de monitoreo desde Database Actions.

## Actividades

1. SQL Worksheet.
2. Crear usuario `DEV_USER` con `DB_DEVELOPER_ROLE`.
3. Habilitar REST, GraphQL, MongoDB API y Web access.
4. Revisar limitaciones del usuario DEV_USER vs ADMIN.
5. Usar Performance Hub y SQL Monitoring.
